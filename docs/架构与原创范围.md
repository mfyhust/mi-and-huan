# 架构与原创范围

用户输入 → 条件与任务记忆 → 基础模型选择有限工具 → 服务端校验授权和参数 → 真实工具执行 → 候选与反馈 → 后续任务跟进。

| 模块 | 代码 | 本项目实现的范围 |
|---|---|---|
| Agent循环 | `lib/agent.mjs` | 模型调用、有限工具分派、预算与执行状态、失败标识 |
| 任务与工具 | `lib/service.mjs`、`lib/store.mjs` | 登记、查询、订阅、反馈及业务状态 |
| 解释性匹配 | `lib/matching.mjs`、`lib/appearance-clues.mjs`、`lib/time-clues.mjs` | 不确定条件、日期、部件外观和分项证据 |
| 追问与反馈 | `lib/question-policy.mjs`、`lib/candidate-feedback.mjs`、`lib/search-diagnostics.mjs` | 追问选择、排除恢复、条件变化诊断 |
| 校园地点 | `lib/campus-locations.mjs`、`lib/place-learning.mjs`、`data/` | 来源记录、别名/楼层/区域解析和用户确认记忆 |
| 模型接入 | `lib/model-runtime.mjs`、`lib/api-pressure.mjs`、`offline/local-fetch.mjs` | 基础模型协议适配、并发与冷却、本机目的地限制 |
| 视觉草稿 | `lib/vision-draft.mjs` | 输出约束、提取结果校验、用户确认；不是自研视觉基础模型 |
| 应用与协作 | `offline/`、`api/`、`remote/` | HTTP/SQLite适配、账号、图片权限与人工交接 |

基础模型不维护业务真相；记录、工具结果和执行日志是查询与反馈依据。网页展示动作摘要，不伪造或公开模型内部思维链。工具调用本身不等同授权：认领、地点记忆和交接仍需应用控制及用户确认。

工程来自Sites/Vinext starter，部分身份、构建与通用组件直接保留。原模板许可、第三方署名与内部xunhui兼容标识保留。React、Node、Vite、SQLite、Sharp和图标等是通用依赖。Qwen/Ollama及API模型是第三方基础设施。本项目的自主开发范围是业务核心及其配套实现，不代表基础模型、算法范式或整个模板全部原创。

公开失物项目只用于需求、流程和技术比较，没有用其业务源码、成品Agent、页面或数据代替本项目核心。具体参考及当时的核查局限见 `开源参考审计.md`；该历史审计不保证上游仓库当前状态不变。

`training/`是可选的合成工具调用QLoRA研究脚本，不参与默认启动。历史小规模训练链路通过不代表Agent质量提升；当前Ollama网页模型没有部署历史LoRA适配器，也未进行视觉微调。合成数据、训练环境与权重不随仓库发布，需要按各脚本计划显式准备和独立评测。
