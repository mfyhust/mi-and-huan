## 复现方法

常规软件检查：

```bash
npm ci
npm run verify
npm run build:api-static
npm run build:offline
```

这些命令不下载或调用基础模型，`npm ci`会获取通用工程依赖。CI只运行这些检查，不使用付费API、GPU、真实业务数据或云端部署。

评测脚本默认显示计划；执行前核对参数、数据来源和当前模型状态：

```bash
node evals/run-api-journey.mjs
node evals/run-local-model.mjs
node evals/run-disconnected.mjs
```

显式 `--run` 才运行真实模型，有资源与费用消耗；不要把真实账号记录发给外部模型。断网测试需遵循脚本的操作系统隔离要求，没有外网路由才可作为断网证据。仓库不自动建立该环境或下载模型。
