# 寻回：开源参考审计

核查日期：2026-10-19（北京时间）。

本次覆盖此前讨论的全部五个校园失物项目。通过 GitHub 仓库树、README 和关键源码进行静态审阅；没有安装依赖、执行远程代码、复现精度或验证线上服务。下文“已见实现”仅表示源码存在对应逻辑，不代表运行正确或具备生产条件。寻回采用独立实现，不复制这些仓库的代码、图片、数据或界面。

## 1. Campus Lost & Found / 404 Found

- 仓库：[shivam-de-bug/campus-lost-found](https://github.com/shivam-de-bug/campus-lost-found)
- 审阅时默认分支提交：`4b9f2d7302810e0b7a283a0440777d6c391c68ba`。
- 已见实现：[matcher_siglip.py](https://github.com/shivam-de-bug/campus-lost-found/blob/main/backend/matcher_siglip.py) 使用 SigLIP 2 图像及文本特征、归一化向量和 FAISS 内积检索。无照片登记可用文字特征；结果返回原始分数、展示分数及等级。[main.py](https://github.com/shivam-de-bug/campus-lost-found/blob/main/backend/main.py) 包含登记、搜索、角色及物品状态处理。
- 不能直接沿用的结论：展示分数由原始相似度经人为线性缩放得到，不是经过校准的“属于同一物品的概率”。README 不同实验表的数字也不能成为寻回的成绩。
- Agent 边界：已审阅部分以检索及业务接口为主，没有足够证据表明实现了面向用户反馈的自主多轮工具决策。
- 许可证核查：README 声称 MIT，但审阅时递归仓库树没有发现 LICENSE/COPYING 文件。不能把 README 声明等同于已核实完整授权文本。
- 寻回吸收：文字优先、照片可选、候选可解释、终态物品退出搜索。暂不引入本地大视觉模型；没有实现向量视觉检索时必须明确说明。

- 许可证：递归仓库树未发现许可证文件。README 中即便出现授权主张，也尚未核实到完整授权文本。

## 寻回的独立开发决策

1. **先做真实闭环**：登记 → 澄清 → 搜索 → 排除/更正 → 等待新线索 → 认领申请 → 保管人核实 → 双方交接。
2. **区分运行模式**：本地演示可用可解释规则完成基础流程，明确标注规则模式；真实 Agent 模式由模型调用有限工具并根据结果选择后续动作。不能把规则回复、模型失败回退或预设脚本包装成模型推理。
3. **保留任务记忆**：已知属性、明确未知、排除候选、追问历史、任务状态均保存；排除后不重复推荐，新线索产生后再检查。
4. **写真正的工具轨迹**：从实际执行动作产生记录，展示查询、更新、匹配和通知的结果，避免装饰性“思考中”日志。
5. **限制归属判断权**：模型只帮助生成核实建议；私密特征不进入公开候选或普通搜索上下文；认领、交接由当事人确认。
6. **按实测填写成绩**：测试集含无匹配、相似干扰、地点转移、照片缺失、拒绝候选和终态过滤；发布评测协议和真实结果，不能移植参考项目指标。
7. **保持原创可说明**：说明文档列出所有参考仓库、借鉴的产品思路以及本作品新增的连续任务记忆和工具决策流程。第三方依赖另按各自许可处理。
