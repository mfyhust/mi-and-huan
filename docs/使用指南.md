# 使用指南

## 版本和模型配置

API版入口为 `api/server.mjs`，默认仅监听127.0.0.1:5173。将示例配置复制为私密文件时，使用自己的服务权限和密钥；禁止提交 `api/config.local.json`。基础模型服务有独立的授权、计费、模型名和图片支持范围，本项目不能保证其持续可用。网页会区分模型执行与规则辅助，不应仅凭回复流畅认定模型已执行工具。

本地版入口为 `offline/server.mjs`，默认仅监听127.0.0.1:5174。推理传输固定本机11434端口，不允许外网地址、云模型或私密API配置；模型缺失时不自动下载或切云。`offline/config.example.json` 给出模型名；修改模型前应核对服务端限制与评测结果。实际第三方运行器和模型许可见 `docs/模型许可/`。

API与离线版默认使用不同数据目录；不要用同一个目录启动两个进程，也不要把两版当成同步副本。保存的任务和站内线索需在同一个版本、同一个工作区内查看。

## 完整寻物流程

1. **拾获登记**：填写物品类别、公开外观、拾获时间和地点。保管去向另填，不能代替拾获地点。私密核实特征不公开展示。
2. **图片草稿**：上传图片后发起外观提取，核对类别、颜色和可见细节，再修改确认。不要把模型猜测作为事实，草稿不能证明归属。
3. **描述寻物**：输入物品、可能地点和时间。地点支持“五餐二楼靠窗”等原话；未确定的建筑、楼层和属性保留范围。
4. **更正线索**：可以说“不是二楼，是三楼”“颜色记不清”。检查任务条件和实际查询记录；不记得的信息不应反复逼问。
5. **核对候选**：查看吻合、冲突和待核实信息；按差异回答问题或排除候选。误排除可恢复。
6. **等待新线索**：用户明确选择持续留意后订阅，新登记触发站内检查。任务状态保存，刷新或进程重启后仍可恢复；浏览器清理身份信息可能影响工作区访问。
7. **认领交接**：由失主提交说明，保管人核实，使用交接口令并由双方确认。模型不自动确认所有权或归还。

新地点或别名先形成草稿，用户确认后再写入可检索记忆；这些地点明确标为用户补充，不冒充官方数据。不编造坐标、地图、楼层布局或招领合作点。

## 可选局域网多人体验

这不是公网托管或GitHub Pages部署。需要同一可互通的私有IPv4网络，主机与服务保持运行，并自行选定访问口令。不要复制测试中的合成口令作为正式部署凭据。

以本机局域网地址192.168.1.20为示例；运行前必须换成你自己的地址，不能照抄：

```bash
export MIGUI_DEMO_ORIGIN="http://192.168.1.20:5184"
read -rsp "输入你自行设置的体验口令：" MIGUI_DEMO_CODE
echo
export MIGUI_DEMO_CODE
bash 启动校内体验.sh local
```

脚本强制局域网范围；`local`表示本机模型版，`api`表示API版。启动前构建对应网页，并分别准备本机模型或私密API配置。多人入口默认使用 `.remote-data/`，选项和限制以 `remote/server.mjs` 为准；部署两版时保持各自工作目录和数据目录独立。

同一个版本中注册测试账号，以拾获者、失主两个账号完成发布与认领。体验口令入口是隔离合成演示，不等同真实账号共享业务。普通HTTP局域网访问未提供端到端保密能力，现阶段只作受控测试，不收集真实敏感资料。

## 常见问题

| 现象 | 检查方式 |
|---|---|
| 网页提示尚未构建 | 分别运行 `npm run build:api-static` 或 `npm run build:offline` |
| `node:sqlite`不可用 | 核对Node版本，工程最低22.13，已测24.22.1 |
| API无响应或限流 | 核对权限、模型名和网络，按等待提示手动重试；规则辅助不是模型成功 |
| 离线模型不可用 | 确认本机11434服务、模型名、权重与视觉投影已准备，缺失时不会自动下载 |
| 无匹配候选 | 当前资料库可能没有合适记录；核对条件、保留不确定性或订阅，不伪造候选 |
| 新地点没有记住 | 草稿须经用户确认，不是模型提出后即写入 |
| 对方看不到记录 | 两人须在同版账号模式，检查是否仍处于隔离合成演示 |
| 其他电脑无法打开 | 检查实际私有IP、端口、网络隔离和防火墙；默认个人版只监听本机 |

停止个人服务通常使用Ctrl+C。保留数据目录和私密配置；备份这些文件时自行管理权限，不提交到GitHub。
